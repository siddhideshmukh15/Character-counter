# Character Counter

A simple **Character Counter** built using Python. 
This beginner-friendly project counts the 
total number of characters in a word or sentence.

## Features

- Accepts a word or sentence from the user
- Counts the total number of characters
- Includes spaces and punctuation
- Displays the character count clearly
- Simple and beginner-friendly

## Technologies Used

- Python
- Strings
- `len()`
- User input
- Variables

## Concepts Learned

- Working with strings
- Taking user input
- Using the `len()` function
- Variables
- Basic string handling
